# 模型鹈鹕智商对比平台（pelican-iq）

**给模型一辆自行车，看看它能不能画好鹈鹕。**

同一道创作挑战（生成一段可运行的「鹈鹕骑自行车」单文件 HTML 动画），让多个模型定时生成，把结果推送到画廊里，方便直观地浏览和比较。画面之外，调用协议、思考强度、耗时和 token 用量也一并记录，让每份样本都有更多上下文。

技术栈：**Node.js 20.9+ / Express / better-sqlite3（SQLite）/ 原生前端**，无构建步骤，`node src/server.js` 即可运行。

## 快速开始

```bash
npm install

# 1. 配置环境变量
cp .env.example .env
# 编辑 .env：设置 ADMIN_PASSWORD（必填）与 SESSION_SECRET

# 2. 可选：写入演示数据（无 API Key 也能看到画廊效果）
npm run seed

# 3. 启动
npm start
```

- 前台画廊：<http://localhost:3000/>
- 后台管理：<http://localhost:3000/admin>
- 健康检查：`GET /api/health`

## 使用流程

1. 打开 `/admin`，用 `ADMIN_PASSWORD` 登录。
2. 新增模型：分三步（连接上游 → 选择模型 → 配置保存）。填写分组名称（同名模型在画廊与模型管理中归为一行）、协议、Base URL（**保存后自动记录，下次可下拉选取历史**）、API Key，获取列表后**可多选多个模型 ID**——每个模型可单独设置思考强度、生成间隔、保留样本数、排序与启用状态，一次提交批量创建。模型管理页同样按分组聚合：一组一行（显示模型数、启用数、最早下次生成），可展开查看/操作各子模型，支持整组「全部运行」与「删除」。
3. 保存后调度器按间隔自动调用模型；也可点「立即运行」手动触发一次。
4. 打开 `/` 查看画廊：**每个分组一行**（仿 jiji.cc Pelican 画廊布局）——左侧为分组信息栏（名称、记录数、**模型切换标签**：全部 / 各模型 ID，点击切换该行显示哪个模型的鹈鹕列表），右侧为横向滚动的紧凑样本卡片条（236px 宽、3:2 动画预览、状态/Token、时间与耗时），行尾「加载更多」。**生成中实时卡片**：模型生成时，该行行首出现一张蓝色高亮的「⟳ 正在生成」实时卡片（带旋转图标与已输出字符数，每 2 秒更新），完成后自动被新样本卡片接替；点击实时卡片可查看本次发送的提示词与流式输出的实时内容（含思考过程）。静止的卡片右上角显示下次生成倒计时（⏳ N 分钟后）。
5. 点击卡片打开详情弹层：大图预览、指标明细、原始 HTML。
6. 画廊每 15 秒自动轮询刷新，新样本无感出现。

**自动获取模型列表**：在后台新增/编辑模型时，填写 Base URL 与 API Key 后点击「获取模型列表」，服务端会调用上游 `GET /models` 拉取可用模型并填充选择列表，无需手动填写模型 ID。

**视觉基准**：画廊第一行是「视觉基准（参考实现）」——移植自 PelicanBench 的手写参考动画（海岸/黄昏/夜路三套配色，含 IK 两段式腿、同步踩踏、辐条车轮），作为人工对照的标准答案，不参与调度。

**详情页**：预览 / 源码 / 提示词三个 Tab，支持下载 HTML、复制源码；检测到外部资源时显示警告横幅。

**人工判断**：详情页提供 8 项检查清单（喙与喉囊、身体结构、车轮、车架、踩踏同步、循环衔接、无外部依赖、自适应），勾选即保存，卡片显示 ✓ N/8 评分。

**生成日志**：后台「生成日志」视图实时显示模型生成鹈鹕的提示词与内容——生成中（蓝色高亮）流式正文与思考内容逐块累积，内容区自动滚动到底部跟随输出（上翻查看历史时不打扰），完成后显示耗时与 token；每 1 秒轮询、DOM 就地更新（不重置滚动与展开状态），只保留最新 50 条（内存环形缓冲，重启清空）。

**模型连通性测试**：模型管理表格每行有「测试」按钮，编辑弹层有「测试连接」按钮——向模型发送一句话（「请回复收到」），有文本回复即测试成功，显示耗时与回复内容；失败时显示上游错误（Key 无效、网关超时等）。编辑时 Key 留空自动使用已保存的 Key，测试不写入数据库、不消耗保留额度。

## 目录结构

```
pelican-iq/
├── src/
│   ├── server.js       # Express 入口：静态文件 + API 路由 + 启动调度器
│   ├── db.js           # SQLite 初始化、建表、数据访问（API Key 永不回传明文）
│   ├── llm-client.js   # 模型调用（三种协议、思考强度、token 用量解析、失败重试）
│   ├── scheduler.js    # 定时调度器：每 30s 扫描到期模型，串行执行
│   ├── auth.js         # 管理端口令登录 + HMAC 签名 Cookie 会话
│   ├── extract.js      # HTML 提取 / 预览 CSP 注入 / 外链检测
│   └── prompt.js       # 标准创作挑战题目
├── public/             # 前台画廊与后台管理（原生 HTML/CSS/JS）
├── scripts/seed-demo.js
└── data/               # SQLite 数据库（pelican-iq.db，已 gitignore）
```

## 数据模型

- **models**：模型配置（协议、Base URL、API Key、模型 ID、思考强度、生成间隔、**保留样本数 retention（默认 10）**、启用、排序、lastRunAt / nextRunAt）
- **results**：每次生成的样本（动画 HTML、协议、思考强度、prompt、输入/输出/总 token、耗时、成功/失败、错误信息、外部引用）
- **admin_logs**：管理操作日志

## API

**公开**：`GET /api/gallery`（按模型分列）、`GET /api/results/:id`、`GET /api/results/:id/preview`（注入 CSP 的沙箱预览）、`GET /api/health`

**管理端**（Cookie 会话）：`POST /api/admin/login|logout`、`GET /api/admin/session`、`GET|POST /api/admin/models`、`PUT|DELETE /api/admin/models/:id`、`POST /api/admin/models/:id/run`（立即生成）、`POST /api/admin/fetch-models`（从上游拉取模型列表）、`GET /api/admin/overview`

## 安全说明

- API Key 明文存储在服务端 SQLite（单机自部署场景），**任何接口都不会回传明文**，列表只显示掩码（`sk-f***3456`）；错误信息中的 Key 也会被脱敏。
- 动画预览运行在 `sandbox="allow-scripts"` 的 iframe 中，并注入 CSP 禁止外链（`default-src 'none'`），模型生成的代码无法访问本站数据或外网资源。
- 管理会话使用 HttpOnly + SameSite=Strict 的签名 Cookie，12 小时有效。
- 生产部署请置于 HTTPS 反向代理之后。

## 调度行为

- 调度器每 30 秒 tick 一次，扫描 `enabled=1` 且 `next_run_at <= now` 的模型，**串行**执行（避免并发打爆上游）。
- 每次运行（无论成败）后 `next_run_at = now + interval_minutes`；失败同样写入 results，画廊中以灰色卡片呈现，保留上下文。
- **流式生成（绕过网关超时）**：OpenAI Chat 协议默认直接走 SSE 流式——数据持续流动，网关（nginx）不会判空闲超时；若网关不支持流式（400 报错）自动退回非流式并记住该网关。Anthropic / Responses 协议非流式优先，遇 502/503/504 自动切换流式重试（流式成功后记忆，后续直接流式）。三种协议的流式响应均可解析，token 用量通过 stream_options / 事件中的 usage 获取。
- **样本保留数**：每个模型只保留最新 `retention` 条样本（默认 10，后台可改为 1–500），每次生成后自动裁剪旧样本；服务启动时也会清扫一次历史积压，防止硬盘爆满。
- 同一模型运行中加锁，手动「立即运行」与调度共用同一条执行路径，不会重复触发。
- 服务重启后 3 秒内先跑一次 tick，处理停机期间积压的到期任务。

## 环境变量

| 变量 | 说明 |
| --- | --- |
| `PORT` | 服务端口，默认 3000 |
| `ADMIN_PASSWORD` | 管理后台登录口令（必填，≥4 字符） |
| `SESSION_SECRET` | 会话签名密钥（建议 `openssl rand -hex 32`；未设置时重启后所有会话失效） |
| `GENERATION_TIMEOUT_MS` | 单次生成总超时（毫秒），默认 600000（10 分钟）。思考型模型推理较慢时可调大 |
